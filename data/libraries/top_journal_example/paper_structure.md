# 顶刊论文写作风格示例：框架分析论文结构（范文库）

**来源**：Journal of Communication 类目（框架研究范文结构）

## 结构模板
1. 摘要（背景/方法/结果/意义四要素，200-300 字）
2. 引言（研究背景 → 问题提出 → 研究目的）
3. 文献综述（框架理论脉络 → 航天传播研究现状 → 研究空白）
4. 方法（样本 → 类目构建 → 编码程序 → 信度检验）
5. 发现（框架分布 → 国别比较 → 关键叙事呈现）
6. 讨论（解释发现 → 与理论对话 → 局限）
7. 结论（回答 RQ → 贡献 → 展望）

## 学术语言规范（减少"AI味"要点）
1. 用精确数字替代空洞副词（"显著高于"配统计值，而非"非常高"）
2. 论断必须有证据支撑，区分"数据显示"与"本文推断"
3. 避免模板化排比与无信息量套话
4. 术语首次出现给定义，后续保持一致

## 评审常用维度（对应评审模拟器）
创新性、方法规范性、论证逻辑、文献覆盖度、学术语言
