# 顶刊论文写作风格示例：方法、结果与讨论范式（范文库）

**来源**：《Communication Methods and Measures》《Journal of Communication》类目

## 方法（Method）写作范式
1. **设计总述**：研究类型（内容分析/实验/调查）、总体与样本、设计理由
2. **抽样透明**：样本来源、时间范围、抽样规则、最终样本量（含排除说明）
3. **测量与编码**：
   - 变量操作化定义 + 测量工具（附量表来源）
   - 编码手册描述 + 编码者培训过程
   - 信度报告：Cohen's κ / Krippendorff's α（>0.70 为可接受，报告具体值）
4. **分析策略**：统计方法、软件、显著性标准、稳健性检验
5. 可复现性：附录提供编码表/问卷/分析脚本

## 结果（Results）写作范式
1. **描述先行**：先呈现描述统计（样本特征、基础分布）
2. **假设对应**：每个 RQ/H 一个小节，先回顾假设再呈现检验结果
3. **表格规范**：统计表自足（标题、N、显著性标注、效应量）、正文引导不重复
4. **效应量报告**：不仅 p 值，报告 Cohen's d / η² / 回归系数
5. **不做过度解释**：结果部分只陈述事实，解释留给讨论

## 讨论（Discussion）写作范式
1. **核心发现重述**：第一段概括主要发现（对应 RQ/H）
2. **理论对话**：发现与文献的印证/分歧（"本研究支持…但挑战…"）
3. **解释机制**：对意外结果给出理论解释
4. **局限声明**：内部/外部效度限制、方法局限（诚恳但不过度自我否定）
5. **未来方向**：基于局限提出具体可做的后续研究
6. **实践意义**：对传播实践/政策/国际传播工作的启示（2-3 条具体建议）

## 常见问题规避
- 结果与讨论混写（顶刊严格分离）
- 局限部分敷衍（评审关注点）
- 过度宣称因果（相关性研究措辞谨慎）
