# 顶刊论文写作风格示例：数据、表格与可视化呈现范式（范文库）

**来源**：SSCI 传播学期刊（Journal of Communication / Communication Research）类目

## 数据呈现基本原则
1. **"表格/图自足"**：读者不读正文也能理解——标题完整（变量、样本、单位）、脚注说明显著性标记与效应量
2. **一表一逻辑**：每张表只回答一个问题；行/列顺序按逻辑或量值排列
3. **正文引导**：正文不重复表中全部数字，只说"如表 1 所示，……"并指出关键模式
4. **数字规范**：
   - 小数位一致（报告 p < .001 或 p = .023）
   - 报告效应量（Cohen's d、η²、β 与 SE）
   - 统计显著 ≠ 实质显著：结合效应量解读

## 表格规范
- 表头：Table 1（编号）+ 说明性标题（Study Characteristics）
- 结构：主栏（variables）与宾栏（conditions/groups）；合并单元格控制密度
- 显著性标记：* p < .05, ** p < .01, *** p < .001（脚注说明）
- 变量名用完整名称而非缩写（除非表内注明）

## 图形规范
- 类型匹配：类别比较→柱状；趋势→折线；分布→箱线/直方；关系→散点（加拟合线）
- 坐标轴：标注单位与刻度；图例清晰；避免 3D 效果与装饰
- 配色：灰度/色盲友好配色；线条粗细区分
- 标题：Figure 1 + 完整说明（含 N 与检验）

## 常见问题规避
- 表图冗余：同一信息图/表二选一
- 表过多过密：只保留支撑核心论证的表
- 不报告效应量与置信区间（现代期刊要求）
