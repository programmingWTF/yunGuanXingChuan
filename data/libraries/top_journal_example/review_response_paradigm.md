# 顶刊论文写作风格示例：同行评审意见回复信范式（范文库）

**来源**：《Journal of Communication》等顶刊 R&R（revise & resubmit）实践

## 回复信结构
1. **开篇致谢**：感谢编辑与评审人的时间与建设性意见
2. **总体回应（summary）**：一段说明根据意见做了哪些系统性修改（point-by-point）
3. **逐条回应**：按评审人（Reviewer 1 / 2 / 3）与意见编号组织

## 逐条回应范式
每条意见的回复模板：
```
**Reviewer 1, Comment 3**: [评审人原意见摘录]
**回应**: 感谢指出。我们已[具体修改]。
  - 修改位置：第 X 页、第 X 段（或 Table X）
  - 修改内容：[引用修改后的关键语句]
  - 解释：[为何这样处理，如引用文献/理论依据]
```

## 关键原则
1. **逐条回应、无一遗漏**：哪怕"暂不修改"也要说明理由（尊重评审）
2. **"感谢+具体修改+位置标注"**：让编辑快速核对
3. **能改则改**：方法细节、表述模糊、补充稳健性检验等低成本意见尽量照做
4. **合理坚持**：确属理论分歧时，礼貌说明立场并补充论证，而非硬刚
5. **补充材料**：新数据、附录、稳健性检验需同步提交

## 常见问题规避
- 只改不答（不解释为何改）——编辑无从判断
- 答而不改（声称已改实则未动）——严重损害信誉
- 语气对抗（"评审人误解了"）——用"我们可能未表述清楚"
- 遗漏意见——用清单核对表（Response to Reviewers）逐项打勾
