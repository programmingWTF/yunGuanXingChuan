# 顶刊论文写作风格示例：引言与文献综述范式（范文库）

**来源**：《Journal of Communication》《Communication Research》类目

## 引言（Introduction）写作范式
1. **问题切入（hook）**：以真实现象/矛盾切入（如"全球太空竞赛重回大众视野"），1-2 句建立重要性
2. **研究空白（gap）**：梳理已有研究局限（方法、语境、样本），明确"尚不清楚/缺乏"之处
3. **研究问题/假设（RQ/H）**：以编号清晰列出，可操作、可检验
4. **理论预览（preview）**：一句话预告理论框架（如"本文以框架理论为基础"）
5. **贡献声明（contribution）**：明确理论贡献与实践贡献
6. 篇幅：500-800 词，逻辑链为"重要性 → 空白 → 问题 → 路径"

## 文献综述（Literature Review）写作范式
1. **组织原则**：按主题/理论/时间线组织（忌文献罗列）
2. **对话式综述**：以"争论"组织文献（A 认为…，但 B 指出…，本文回应…）
3. **经典文献 + 最新文献平衡**：奠基性文献必引，近五年文献为主体
4. **每节收束**：小结与 RQ/H 的衔接（"上述文献表明…，然而…，故提出 RQ2"）
5. **批判性**：不仅描述，更要评估方法局限与结论边界

## 常见问题规避
- 文献综述 ≠ 摘要堆叠：每篇文献需说明"与本文的关系"
- 过度引用二手转述：关键命题回到原始出处
- 综述长度失控：与 RQ 数量匹配（一般占总篇幅 25-30%）
