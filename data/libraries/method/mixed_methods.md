# 方法库：混合方法研究（Mixed Methods Research）

**类型**：qualitative + quantitative 整合
**适用**：单一方法无法完整回答研究问题（如"是什么 + 为什么 + 影响多大"）

## 操作步骤
1. 研究问题拆分：区分描述性/关联性/机制性问题，分配给合适方法
2. 设计选择：
   - 聚敛设计（convergent）：质与量并行收集，结果整合比较（三角验证）
   - 解释性序列设计（explanatory sequential）：量 → 质（用质性解释量化结果）
   - 探索性序列设计（exploratory sequential）：质 → 量（用质性生成量表/假设）
   - 嵌入式设计：一种方法为主，另一种嵌入补充
3. 整合点（integration）：数据收集阶段、分析阶段或解释阶段的"结合"设计
4. 数据分析：
   - 连接（connecting）：序列设计中后一方法结果连接前一方法
   - 合并（merging）：聚敛设计中将两类结果并表/并图
   - 嵌入（embedding）：补充性数据纳入主导分析
5. 报告：方法流程图（JOIN 图）、整合结果表、"荟萃推断"（meta-inference）

## 注意事项
- 方法优先级与顺序需在研究设计中明确并报告
- 质性/量化质量标准分别执行（可信性/可靠性）
- 整合不足是混合方法常见缺陷：需展示两类结果的"对话"
- 时间与资源成本高，样本量需兼顾两类方法要求
