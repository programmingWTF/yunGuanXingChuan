# 方法库：案例研究（Case Study）

**类型**：qualitative（可混合量化）
**适用**：深入理解特定案例（事件、组织、国家、平台）的传播过程与机制

## 操作步骤
1. 案例选择：典型案例（representative）、极端案例（deviant）、关键案例（critical）、纵向案例；明确选择理由
2. 分析单位界定：事件 / 组织 / 报道文本 / 传播过程
3. 多源数据收集（三角验证 triangulation）：
   - 文本数据：媒体报道、官方文件、发布稿
   - 访谈数据：关键人物（记者、传播管理者、专家）
   - 行为数据：转发量、评论、传播路径
4. 分析策略：
   - 时间序列分析（过程追踪，process tracing）
   - 模式匹配（pattern matching）：实证模式与理论预测对照
   - 解释建构（explanation building）
5. 交叉案例比较（multiple-case design）：跨案例复制逻辑
6. 报告：厚描述（thick description）+ 理论对话

## 注意事项
- 概括性问题：案例研究的价值是"分析性概括"（指向理论）而非"统计性概括"（指向总体）
- 主观性控制：编码者间一致性、材料留档、分析链可追溯
- 单案例需给出强选择理由，否则优先多案例设计
- 与内容分析/框架分析结合：案例内做系统文本分析
