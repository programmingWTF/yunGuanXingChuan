# 方法库：焦点小组（Focus Group）

**类型**：qualitative
**适用**：探索受众对科技议题的认知框架、态度形成过程、群体讨论中的意见互动

## 操作步骤
1. 研究目标：明确要探索的认知/态度维度（如公众如何理解航天工程）
2. 组别设计：每组 6-10 人；按人口学/态度分层分组（同质性利于讨论，异质性激发碰撞）
3. 讨论提纲：半结构化（开场破冰 → 核心议题 → 材料刺激 → 收尾）；控制 1.5-2 小时
4. 招募与伦理：知情同意、录音授权、报酬
5. 主持技巧：中立引导、追问、鼓励少数意见、管理强势参与者
6. 转录与编码：逐字转录、主题编码（开放编码 → 轴心编码 → 选择编码）
7. 报告：主题描述 + 典型引语 + 群体互动分析（共识/分歧如何形成）

## 注意事项
- 抽样非代表性：结果用于探索与假设生成，不作统计推断
- 群体效应：从众压力与"社会期望"影响发言；主持需平衡
- 分析单位：既分析个体观点也分析群体互动过程
- 常作为问卷设计的前置（生成题目）或结果解释的补充
