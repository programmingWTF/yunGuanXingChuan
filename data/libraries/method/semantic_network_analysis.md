# 方法库：语义网络分析（Semantic Network Analysis）

**类型**：quantitative + qualitative 混合
**适用**：从文本语料中提取概念及关联，分析话语结构（议题框架、观点网络）

## 操作步骤
1. 文本语料准备：媒体报道/评论/访谈转录（清洗、去停用词、分词/词性标注）
2. 概念提取：高频词、关键词、主题词（TF-IDF）；领域词表辅助
3. 共现矩阵构建：滑动窗口（如 ±5 词）内概念共现次数；或句内共现
4. 网络构建：概念为节点、共现为边（加权）；可阈值化（保留强关联）
5. 网络分析：
   - 中心性：度/中介/特征向量中心性（核心概念识别）
   - 社区发现：概念聚类（Louvain/Infomap）
   - 结构洞：桥接概念
6. 时序语义网络：分时段比较概念网络变化（议题演化）
7. 可视化与报告：NetDraw/Gephi 图 + 中心概念表 + 框架解读

## 注意事项
- 分词质量决定结果（中文尤其重要，需领域词典）
- 窗口大小选择影响共现意义（实验敏感性）
- 语义网络 ≠ 因果关系：共现是相关性证据
- 与框架分析结合：网络中的核心节点=框架的关键装置

## 代表文献
Doerfel (1998, semantic network analysis); 中国语境：政务传播、舆论语义网络研究
