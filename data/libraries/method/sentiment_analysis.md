# 方法库：情感分析（Sentiment Analysis）

**类型**：quantitative
**适用**：媒体报道/社交媒体文本的情感倾向测量

## 操作步骤
1. 明确情感维度：二分类（正/负）或三分类（正/负/中性）或细粒度（情感类别）
2. 文本预处理：分词、去停用词、统一术语
3. 情感计算：词典法（情感词典匹配）或机器学习法（有标注训练集）
4. 效度检验：人工抽样比对（随机 10% 样本，一致性 ≥ 0.85）
5. 聚合分析：按国家/媒体/时段汇总情感分布，结合事件时间线解释

## 注意事项
- 中文情感词典需适配新闻语体（新闻用词中性化，情感较含蓄）
- 讽刺/反讽文本是难点，需人工复核关键样本
- 情感与框架结合分析更有解释力（如威胁框架通常伴随负面情感）
